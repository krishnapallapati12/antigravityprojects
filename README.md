# 🏰 jaikrishnaram.formhouse.com
> **Jai Krishna Ram Farmhouse & 100-Acre Private Sanctuary in Central Hyderabad (Near HITEC City)**

Official website for **jaikrishnaram.formhouse.com**, built with **HTML5, CSS3, JavaScript, React.js**, 4K cinematic videos, and an interactive **Three.js 3D WebGL Engine** featuring real-time 3D waterfalls with water physics, an illuminated swimming pool with water ripple simulation, and a 50-acre 3D buffalo sanctuary with grazing buffalos.

Designed specifically to showcase the estate and operate the **Saturday & Sunday Exclusive ₹5,00,000 Weekend Lease Business**.

   - **3D 50-Acre Buffalo Sanctuary**: 500-buffalo dairy farm representation with grazing head movements, horns, paddocks, and modern sheds.

3. **Weekend Lease Business Engine (Every Saturday & Sunday - ₹5,00,000)**:

## 🚀 How to Open and Run

### Option 1: Double Click `index.html`
Simply double-click `index.html` or right-click and choose **Open with Google Chrome** or **Microsoft Edge**. It runs directly with zero installation or build steps required.

### Option 2: Run via Browser Command
Double click `open_website.bat` or run:
```powershell
Start-Process "index.html"
```
